# 후쿠오카 3박 4일

남자 둘이 먹고 마시며 돌아다니는 후쿠오카 3박 4일 여행 일정표입니다. 하카타·나카스를 중심으로 다자이후, 야나가와, 기타큐슈 모지코까지 다녀옵니다.

사이트: https://cafephilia.github.io/fukuoka-trip/

> 항공권과 숙소는 아직 예매 전이라 나고야 여행과 비슷한 시간대(11:20 출발, 15:00 귀국)와 하카타역 주변 숙소를 가정했습니다. 식당·교통·사진은 2026년 10월에 조사해 채웠고, 「확인 필요」로 적힌 항목은 출발 전에 확인합니다.

## 일정

| 날짜 | 주제 | 주요 일정 |
|---|---|---|
| 1일차 11.19 목 | 도착, 하카타의 밤 | 후쿠오카공항 → 하카타역 → 하카타 잇소 라멘 → 구시다 신사 → 캐널시티 → 오오야마 모츠나베 → 나카스 야타이 |
| 2일차 11.20 금 | 다자이후와 야나가와 | 관광 승차권으로 다자이후 텐만구·우메가에모치 → 모토요시야 장어 세이로무시 → 뱃놀이 → 다이묘 헤테 야키토리 → 텐진 야타이 |
| 3일차 11.21 토 | 모지코와 시모노세키 가라토 시장 | 모지코 레트로 → 간몬 연락선 → 가라토 시장 초밥 → 해저 인도 터널 → 베어 프루츠 야키카레 → 가와타로 오징어 활어회 |
| 4일차 11.22 일 | 오호리 공원, 멘타이주, 귀국 | 다이후쿠 우동 → 오호리 공원·후쿠오카성 터 → 멘타이주 → 하카타역 기념품 → 공항 |

## 채워야 할 것

- 항공편: `src/data/trip.ts`의 `FLIGHTS`, 1·4일차 공항 항목 시각
- 숙소: `HOTEL`, `STAY`, 동선 지도 좌표 `POS.hakata`
- 요금: 공항 버스, 후쿠오카 지하철, 택시처럼 「확인 필요」로 남은 항목

## 자료 출처

- 식당 정보: 공식 사이트, 타베로그, 핫페퍼, 관광 사이트 (각 맛집 카드의 출처 링크, 2026-10 조사)
- 교통 요금: 에키탄, 니시테쓰, 간몬 관광 사이트 (2026-10-19 검색)
- 사진: 위키미디어 커먼즈 (CC 라이선스, 작가와 라이선스는 사진 아래와 `src/data/photos.ts`)

## 기능

나고야 일정표 앱과 같은 구조입니다.

- **날짜별 타임라인**: 일정 종류별 아이콘, 여행 당일에는 지금 할 일 표시
- **이동 방법 비교**: 도보·지하철·전철·버스·택시별 경로, 소요 시간, 요금
- **동선 지도**: 날짜마다 일정 순서대로 번호를 찍은 지도(OpenStreetMap)와 구글 지도 길찾기
- **출발 전 챙길 것·수하물 규정**: 체크 상태는 휴대폰에 저장
- **맛집 탭·메뉴판·택시용 주소 카드**
- **정보 탭**: 항공권, 숙소, 출발 전 할 일, 여행 팁, 교통 요금, 걸어서 가는 거리, 행사, 긴급 연락처
- **오프라인 지원**: 한 번 열면 인터넷 없이도 열림, 홈 화면에 추가 가능
- **편의 기능**: D-day 표시, 주소 해시로 날짜 탭 바로 열기(`#d1`–`#d4`, `#info`), 다크 모드

## 구조

```
src/
  data/trip.ts        여행 정보(TRIP), 일정, 항공편, 체크리스트, 여행 팁, 정보 탭 표
  data/menus.json     식당 메뉴판 데이터
  data/foodspots.json SNS·유튜브 맛집 데이터
  data/photos.ts      관광지 사진과 출처
  types.ts            데이터 타입
  components/         화면 컴포넌트
public/
  sw.js               오프라인 서비스 워커
  manifest.webmanifest
```

## 개발

Node.js 20.19 이상이 필요합니다.

```bash
npm install
npm run dev
```

`main` 브랜치에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 배포합니다. 처음 한 번은 저장소 Settings → Pages에서 Source를 GitHub Actions로 지정해야 합니다.
